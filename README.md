DBMS_Project(E_Diary)


📘 E-Diary Web Application

The E-Diary is a simple digital diary system that allows users to securely record and manage their personal notes online. It replaces traditional handwritten diaries with an easier, faster, and more organized web-based solution. Users can create an account, log in, write their daily thoughts, edit past entries, and delete unwanted notes—making it a convenient platform for personal journaling and record-keeping.

🚀 Features 🔐 User Authentication

User registration

Secure login system

Session-based access control

📝 Diary Entry Management

Add new diary entries

View all personal entries

Edit existing entries

Delete entries permanently

📅 Automatic Date Tracking

Each entry is saved with the current date

💾 Database Storage

All user accounts and entries are stored safely in a MySQL database

🧭 Simple & Clean Interface

Easy-to-use design

Smooth navigation between pages
